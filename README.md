# Finixcode Frontend

A modern, responsive web application built with React 19, TypeScript, and Tailwind CSS 4. This project showcases clean component design with an emphasis on responsive layouts and user experience.

## 🌟 Live Demo

Check out the live site: [Live](https://finix-code-frontend.vercel.app/)

## 📋 Features

- Modern React components using functional patterns
- Fully responsive design that works on all device sizes
- Clean, accessible UI components
- TypeScript for type safety
- Tailwind CSS for styling

## 🛠️ Technologies

- React 19
- TypeScript
- Tailwind CSS 4
- Vite 6
- Lucide React (for icons)
- ESLint 9 (for code quality)

## 📦 Prerequisites

Before you begin, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (v18.0.0 or higher)
- [npm](https://www.npmjs.com/) (v9.0.0 or higher) or [yarn](https://yarnpkg.com/) (v1.22.0 or higher)

## 🚀 Getting Started

Follow these steps to set up the project locally:

### 1. Clone the repository

```bash
git clone https://github.com/rakibul58/Finixcode-Frontend.git
cd Finixcode-Frontend
```

### 2. Install dependencies

Using npm:
```bash
npm install
```

Using yarn:
```bash
yarn
```

### 3. Start the development server

Using npm:
```bash
npm run dev
```

Using yarn:
```bash
yarn dev
```

### 4. Build for production

Using npm:
```bash
npm run build
```

Using yarn:
```bash
yarn build
```

### 5. Preview production build

Using npm:
```bash
npm run preview
```

Using yarn:
```bash
yarn preview
```
